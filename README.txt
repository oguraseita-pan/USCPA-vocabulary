USCPA Lexi — FAR / 英文会計入門 単語学習アプリ

1. 手軽にPCで使う場合: index.html をChromeなどで開いてください。
2. スマホで使う / PC・スマホから同じURLで使いたい場合:
   このフォルダ内の全ファイルを静的Webホスティング（GitHub Pages、Netlify Drop等）にアップロードしてください。
   HTTPSで公開するとホーム画面に追加してアプリ風に使えます。
3. 記憶履歴は各ブラウザ内のlocalStorageに保存されます。端末間の自動同期はありません。
   [設定] → [バックアップを保存（JSON）]から書き出し、別端末で復元できます。
4. 学習データ: 2026年9月1日更新の「FAR 用語（英語）リスト」および「英文会計入門 用語（英語）リスト」。
   全データを重複除去して2,508語の英単語として収録。1語が複数章に含まれる場合、章情報を保持しています。
5. 忘却曲線の復習方式はAnkiの4段階評価を参考にした独自の簡易SRSで、FSRSと同一ではありません。

外部ライブラリ・API不要、インターネット接続なしでも単語表示・学習可能です。
